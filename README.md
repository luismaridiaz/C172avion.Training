# Entrenador C172 — Escuela de vuelo

PWA de un solo HTML (Three.js r128 por CDN) para aprender a volar un Cessna 172: 17 lecciones evaluadas, instructor en vivo, listas de comprobación, VOR/ADF, radio básica, ajustes y calibración.

Funciona offline tras la primera carga (service worker). Sin validar por un instructor real.
